Context: A1 (dropout_style) x A2 (norm) ablation on top of the full
recommended stack (MERLIN + PH(b3,f0.5) + whiteness + polish(0.5) +
edge_boost(1.0)), 700 iters. "final" = historical architecture
(Dropout2d "band" + BatchNorm). Motivations (measured): Dropout2d on the
1-channel LL output zeroes the ENTIRE low-frequency band in ~30% of
passes (training AND the 32-64 MC-dropout inference passes); BatchNorm
runs on batch-1 statistics in train() mode and the EMA model never
updates its BN buffers.

Verdict: pixel+group is the new winning base — the first change that
clears the "serious gain" bar:
 * GT: PSNR +0.64 dB (HH) / +1.51 dB (HV), SSIM 0.796/0.801 ->
   0.834/0.838, EPI(HV) 0.791 -> 0.828, ENL-ROI 135/192 -> 4630/561.
   PSNR, SSIM and EPI all rise together, so the ENL jump is genuine
   smoothing of homogeneous areas, not blur (visual check: structures and
   edges intact, HV keeps MORE detail than "final").
 * Real: corr(HV,VH) 0.9924 -> 0.9996, ratio-ENL(HV) 0.499 -> 1.120
   (ideal 1), ENLr(HH) 0.879 -> 0.904, EPI(HV) 0.656 -> 0.714.
   ENL-ROI on the textured urban ROIs is lower (1.20/1.50 -> 1.01/1.28) —
   the texture-saturated ROI metric disagrees with the ratio metric here;
   the ratio-image says the removed component is now much closer to pure
   speckle.
 * Interactions matter: "pixel" ALONE collapses the cross-pol channel on
   GT (PSNR(HV) 21.4 -> 17.8, ENL(HV) 14) — per-pixel dropout with
   batch-1 BatchNorm is unstable; "group" alone is a modest, consistent
   improvement. Only the combination unlocks the gain. Document both.
